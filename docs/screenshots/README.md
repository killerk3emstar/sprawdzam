# Zrzuty ekranu

Do prezentacji. Dane na zrzutach są testowe: numery są zamaskowane albo fikcyjne (+48 600 100 200), rozmowy pochodzą z trybu demo. Zrzuty apki są z emulatora Androida (ten sam kod co na telefonie demo), zrzuty stron z przeglądarki na Macu.
